Power Meter Flasher

LilyGO T3-S3 · SX1262

Install from the browser

  1. Use Chrome or Edge on a computer (Web Serial is not available in Firefox, Safari or on phones).
  2. Connect the board with a USB-C data cable. Antenna on first.
  3. Press the button, pick the port (USB JTAG/serial debug unit) and confirm.

This browser cannot flash. Use Chrome or Edge on a desktop. Flashing needs a secure (https) page.

Both boards get the same firmware. Which one is the basement node and which one the gateway is chosen afterwards on the setup page.

Fresh install or re-flash?

The installer asks whether to erase the device. Tick it for a new board or to start over. Leave it unticked to keep the settings and pairing of a board that was already set up.

Board not found?

  1. Hold BOOT, press and release RST, then release BOOT. The board is now in download mode.
  2. Try again. When it finishes, press RST once so the new firmware starts.
  3. Still nothing: try another cable. Many USB-C cables only carry power.

Later updates

You do not need this page again. Updates go over WiFi: open the board's web page → System → Firmware-Update and upload the …-update.bin from the latest release.
